Smart Crop Recommendation System

The Smart Crop Recommendation System is a Java console application that recommends a suitable crop based on soil and environmental conditions. It uses Nitrogen, Phosphorus, Potassium, Temperature, Humidity, Rainfall, and Soil pH to calculate a suitability score for different crops.
